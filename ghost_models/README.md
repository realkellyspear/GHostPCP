# GHost PCP — Local Models (`ghost_models`)

Drop your `.gguf` language model files into this directory.

Recommended starting model:
- `Qwen3-14B-Q5_K_M.gguf` (fast, strong instruction adherence, and follows the GHost PCP grounding prompt cleanly)

When `GHost-PCP.exe` (or `python ghost_pcp.py`) is running, open **[ CONFIG ]** in the top bar to refresh the model list, run **CHECK FIT** to preview automatic NVIDIA VRAM layer allocation, and click **MOUNT**.
